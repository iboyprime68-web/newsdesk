# newsdesk

Always-on news wire for the BritAsia news desk Discord server. A GitHub Actions
workflow polls ~27 curated RSS feeds every 5 minutes, deduplicates and clusters the
same story across outlets, scores everything, and posts to Discord:

- **#breaking-news** — score ≥ 70 + corroboration → posts with an @Breaking-Ping mention
- **#top-stories** — score ≥ 48, shows how many outlets cover each story
- **Desk channels** — uk / world / south-asia / entertainment / sport-cricket / viral-trending
- **#instagram-ideas** — an LLM (OpenRouter, GLM 5.1 with fallbacks) rates each top story's
  Instagram-worthiness and writes a hook headline
- **#daily-briefing** — top 10 of the last 24h, first run after 8am UK
- **#bot-status** — feed-health warnings and run failures (staff only)

## Latency expectations

GitHub's cron drifts: runs fire every 5 minutes *nominally*, but 5–30 min delays at busy
hours are normal and some runs are silently skipped. Median story latency is ~6–9 min
after an outlet publishes. For an instant check, run the workflow manually:
Actions → newsdesk → Run workflow. Every pipeline stage is a pure module, so moving to
a 1-minute Cloudflare Workers cron later is a small adapter change, not a rewrite.

## Layout

- `src/run.js` — orchestrator (`--dry-run`, `--explain` flags)
- `src/lib/` — feeds, dedupe/cluster, score, trends, ai, discord, briefing, state
- `config/feeds.json` — the feed list (tier `breaking` = every run, `standard` = every 3rd)
- `config/scoring.json` — weights, thresholds, keywords, flood caps, AI model chain
- `config/discord.json` — channel/role IDs (generated by setup, committed; IDs aren't secrets)
- `setup/` — one-time server builder, welcome post, state-branch init, live rehearsal
- State lives on the orphan `state` branch (one JSON, committed each run — this also keeps
  the scheduled workflow from GitHub's 60-day auto-disable)

## Secrets

`DISCORD_BOT_TOKEN` and `OPENROUTER_API_KEY` exist **only** as GitHub Actions secrets and
in a local gitignored `.env`. Never commit them — this repo is public. If a token ever
leaks, rotate it in the Discord Developer Portal immediately.

## Local dev

```
npm install
npm run dry          # fetch + score, print what would post, no Discord writes
npm run setup:server # (needs .env with DISCORD_BOT_TOKEN + GUILD_ID) build the server
```

`.env` file:

```
DISCORD_BOT_TOKEN=...
GUILD_ID=...
OPENROUTER_API_KEY=...
```

## Tuning

Everything editorial lives in `config/scoring.json`: tier thresholds, breaking keywords,
per-channel flood caps, AI model chain and the minimum IG score for #instagram-ideas.
Edit, commit, done — no code changes needed.
